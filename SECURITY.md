# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could affect users of this project.
Use GitHub's **Report a vulnerability** flow in the Security tab and include:

- affected component and version;
- minimal reproduction steps;
- expected security impact;
- suggested remediation, if available.

Secrets, private repositories and credentials must never be pasted into the demo. The app is intended to analyze public Pull Requests.
